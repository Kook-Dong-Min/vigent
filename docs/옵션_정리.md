# VIGENT 수정 가능 옵션 모음 (2026-10-12 기준)

이 서비스에서 **코드를 고치지 않고 바꿀 수 있는 설정**을 한곳에 모았다. 각 항목은 `어디서 바꾸나 · 기본값 · 무엇이 바뀌나 · 주의`.
기본값은 2026-10-12 `config/tuning.yaml` 등 실제 파일에서 추출했다.

> **바꾼 뒤 반영 방법**
> - `config/tuning.yaml`·`themes/safety/vision.yaml`·환경변수·알림/구역 설정 → **서버 재시작**(바탕화면 `VIGENT Safety 종료.bat` → `VIGENT Safety 시작.bat`). tuning 은 서버가 시작할 때 한 번 읽어 캐시한다.
> - 확대뷰 박스 표시(아래 §4, `config/tuning.yaml` `hub.box_*`) → 값을 바꾸고 **브라우저 새로고침**(서버가 페이지에 주입).
> - 카메라 추가·FPS·위험구역 → 관제 화면(`/safety-hub`)에서 바꾸면 해당 카메라 워커만 자동 재시작(서버 재시작 불필요).

## 4. 확대뷰 박스 표시 (config/tuning.yaml `hub` — 서버가 페이지에 주입, 브라우저 새로고침)

`window.VIGENT_HUB_CFG` 로 주입하므로 **tuning.yaml 만 고치고 새로고침**하면 된다.

| 키 | 기본 | 뜻 |

| `hub.box_render_tau` | 40 | 렌더 평활 시간상수(ms). 높을수록 부드럽지만 지연↑. 0=평활 끔 |
| `hub.spot_poll_ms` | 50 | 확대뷰 검출 폴링 주기(ms). 낮을수록 반응↑·요청↑ |

| `hub.tile_video` | 확대뷰를 따름 (전역 파일은 boxed) | [2026-11-16] 왼쪽 타일 영상. `boxed` = 타일도 실시간 박스 영상, `snapshot` = 예전 타일(1.3초마다 정지화면, 박스 없음). 실시간은 타일 3개 + 확대뷰까지(브라우저 동시 연결 한도), 그 뒤 카메라는 약 1초 간격 박스 정지영상. 여러 대일 때 검출 속도 영향은 **미측정** |

확대뷰 지연이 거슬리면 화면의 오프셋 버튼(−50/+50 ms)으로 미세조정.

> 위 외에도 코드가 읽는 고급/내부 변수(`VIGENT_EDGE`·`VIGENT_ZONE_TILE`·`VIGENT_HANG_TIMEOUT`·`VIGENT_FAULT_STOP_DETECT`·`VIGENT_GO2RTC_URL`·`VIGENT_GO2RTC_RTSP_PORT` 등)가 있다 — 특별한 사유가 없으면 두는 것이 안전.
